# .gaf File Format

https://files.tauniverse.com/files/ta/resources/tutorials/ta-design-guide/browse-online/tadesign/gafdesc.htm

The GAF file format is simply a collection of images that can be grouped together into an animation sequence. They are typically used for: animations, "gadgets", and model textures.
